# 한 번에 요청하는 방법

## 새 프로젝트: 설계부터

```text
$human-centered-project-builder

BUILD_REQUEST.md를 읽고 새 프로젝트를 시작해.

지금은 코드를 작성하지 마.
먼저 문제, 요구사항, 성공 기준, Architecture, 주요 기술 선택을 정리하고
PROJECT.md / REQUIREMENTS.md / ARCHITECTURE.md / DECISIONS.md /
AGENTS.md / TASK-001.md 초안을 만들어.

사람이 이해하기 쉬운 코드와 프로젝트 구조를 최우선 요구사항 중 하나로 반영해.
불확실한 중요한 결정만 질문해.
```

## 설계 + 구현까지

```text
$human-centered-project-builder

BUILD_REQUEST.md와 현재 저장소를 기준으로 작업해.

설계를 먼저 정리한 뒤 승인된 범위에서 TASK-001부터 구현해.

코드는:
- 명확한 이름
- 단순한 제어 흐름
- 한 책임의 함수/모듈
- 불필요한 추상화 금지
- WHY 중심 주석
- README 코드 읽는 순서
를 지켜.

구현 후 테스트를 실제 실행하고,
Acceptance Criteria와 Readability Review 결과를 보고해.
```


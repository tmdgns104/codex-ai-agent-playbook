# Human Readable Code 시작 Prompt

## 구현

```text
$human-readable-code

이 기능을 구현해.

작동만 하는 코드가 아니라 다른 개발자가 처음 읽어도
실행 흐름과 책임을 추적할 수 있는 코드로 작성해.

특히:
- 의미 있는 이름
- 한 함수의 명확한 책임
- 불필요한 추상화 금지
- 핵심 데이터 흐름이 코드에 드러나게
- 주석은 '무엇'보다 '왜'
- 테스트 수행
- README의 코드 읽는 순서 갱신

완료 후 주요 실행 흐름과 중요한 파일/함수를 설명해.
```

## 기존 코드 가독성 리뷰

```text
$human-readable-code

코드를 먼저 수정하지 말고 가독성 리뷰부터 해.

다음을 HIGH / MEDIUM / LOW로 분류해:
- 이름
- 함수 책임
- 중첩/제어 흐름
- 숨은 side effect
- 불필요한 추상화
- 프로젝트 구조
- README와 실제 코드 불일치

그 다음 최소 변경 리팩터링 계획을 제안해.
```

## 학습용 프로젝트

```text
$human-readable-code

이 프로젝트는 결과물뿐 아니라 코드를 읽으며 기술을 배우기 위한 프로젝트야.

핵심 메커니즘을 프레임워크 뒤에 숨기지 말고,
단순하고 직접적인 구현부터 시작해.

구현 후:
1. 데이터 흐름
2. 파일별 역할
3. 함수별 역할
4. 왜 이렇게 설계했는지
5. 초보자가 헷갈릴 부분
을 설명해.
```

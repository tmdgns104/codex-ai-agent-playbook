# Visual QA

Inspect rendered slides whenever possible.

## Every Slide

- [ ] Nothing is clipped.
- [ ] Nothing unintentionally overlaps.
- [ ] No text touches slide edges.
- [ ] Title is clearly separated from body.
- [ ] Main message is visible within a few seconds.
- [ ] Body text is not excessively small.
- [ ] Line spacing is readable.
- [ ] Alignment looks intentional.
- [ ] Margins are consistent.
- [ ] Images preserve aspect ratio.
- [ ] Icons/images are not blurry.
- [ ] Contrast is sufficient.
- [ ] Callouts do not obscure the object they explain.
- [ ] Diagram arrows are visible and unambiguous.
- [ ] Chart labels/legends are readable.
- [ ] Tables are not used when a diagram/chart would communicate better.

## Whole Deck

- [ ] Layout system is consistent.
- [ ] Typography hierarchy is consistent.
- [ ] Color meanings are consistent.
- [ ] Section transitions are obvious.
- [ ] Similar slide types use similar layouts.
- [ ] Dense slides are balanced by simpler slides.
- [ ] No accidental duplicate slide.
- [ ] No placeholder content remains.

## Visual QA Status

Use one:

PASS
PASS WITH NOTES
FAIL
UNVERIFIED

If slides were not rendered and seen, do not use PASS.

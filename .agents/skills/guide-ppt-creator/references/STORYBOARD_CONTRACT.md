## Storyboard Acceptance

- [ ] Each slide has one primary message.
- [ ] Story order is understandable without hidden assumptions.
- [ ] No duplicate slides saying the same thing.
- [ ] Important source material has a planned destination.
- [ ] Audience prerequisites are considered.
- [ ] Opening explains why the topic matters.
- [ ] Ending provides a clear takeaway or next action.

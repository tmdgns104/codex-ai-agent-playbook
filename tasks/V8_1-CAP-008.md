# V8_1-CAP-008 - Installed Launcher / Arbitrary Repository Integration

상태: **APPROVED - READY FOR IMPLEMENTATION**

선행 Task:

## 목적

CAP-007 launcher를 Playbook source repository 안에서만 동작하는 prototype이 아니라, `install.ps1`로 설치한 뒤 **임의의 Git repository에서 실행 가능한 실제 사용자 흐름**으로 연결합니다.

정상 사용에서 사용자는 Skill 이름이나 Capability Library 경로를 알 필요가 없습니다.

## 해결할 구조 문제

CAP-007까지는 `--root`가 동시에 다음 두 의미를 가졌습니다.

1. Codex가 작업할 target repository
2. `capability-library/`가 존재하는 Playbook source root

설치 후 다른 프로젝트에서 실행하려면 이 두 root를 분리해야 합니다.

CAP-008에서는:

```text
Target Repository
  = 사용자가 실제 수정할 Git repository

Catalog Root
  = Playbook capability-library가 설치된 위치
```

로 분리합니다.

## 설치 Layout

Windows 기준:

```text
%USERPROFILE%\.codex\
  AGENTS.md
  playbook-harness\
  capability-library\

%USERPROFILE%\.agents\skills\
  <기존 Core managed Skills 7개>
```

`capability-library/skills/optional/*`는 `.agents/skills`에 영구 설치하지 않습니다.

## Launcher Catalog 자동 탐색

`playbook_launch.py`는 자신의 파일 위치를 기준으로 Catalog Root를 결정합니다.

Source checkout:

```text
<playbook-repo>/harness/activation/playbook_launch.py
-> catalog root = <playbook-repo>
```

Installed:

```text
~/.codex/playbook-harness/activation/playbook_launch.py
-> catalog root = ~/.codex
```

두 위치 모두 `<catalog-root>/capability-library/registry.json` 계약을 만족합니다.

사용자는 별도 catalog option을 지정하지 않습니다. 테스트/진단용 override만 내부적으로 허용할 수 있습니다.

## Materializer / Bridge 계약

- `repository_root`: runtime과 Codex 작업 대상
- `catalog_root`: registry와 optional Skill source
- bridge target은 계속 repository 내부 `.playbook-runtime`만 허용
- optional Skill source는 catalog root의 `capability-library` 아래만 허용
- target repo에 `capability-library`를 복사하지 않음

## Installer

`install.ps1`:

- 기존 AGENTS / Core Skills / harness 설치 유지
- `capability-library`를 `%USERPROFILE%\.codex\capability-library`에 fingerprint 기반 idempotent 설치
- 변경 시 기존 설치는 timestamp backup 후 교체
- optional Skill은 discovery path에 설치하지 않음

`verify-install.ps1`:

- installed capability library fingerprint 검증
- 기존 global verification 유지

`uninstall.ps1`:

- managed installed capability library 제거
- 사용자 다른 파일은 건드리지 않음

## Quickstart

설치 후 임의의 Git repository에서:

```cmd
python "%USERPROFILE%\.codex\playbook-harness\activation\playbook_launch.py" --root . --task "<작업>"
```

Skill 선택은 자동입니다.

실제 Codex를 띄우지 않는 확인:

```cmd
python "%USERPROFILE%\.codex\playbook-harness\activation\playbook_launch.py" --root . --task "JWT 인증 오류를 수정하고 regression test를 실행" --dry-run
```

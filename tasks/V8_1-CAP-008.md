# V8_1-CAP-008 - Installed Launcher / Arbitrary Repository Integration

상태: **WINDOWS VERIFICATION IN PROGRESS**

선행 Task:

- `V8_1-CAP-001` ~ `V8_1-CAP-007` — **COMPLETE - VERIFIED**

## 목적

CAP-007 launcher를 Playbook source repository 안에서만 동작하는 prototype이 아니라, `install.ps1`로 설치한 뒤 **임의의 Git repository에서 실행 가능한 실제 사용자 흐름**으로 연결합니다.

정상 사용에서 사용자는 Skill 이름이나 Capability Library 경로를 알 필요가 없습니다.

## 해결한 구조 문제

CAP-007까지 `--root`가 target repository와 Playbook catalog root 역할을 동시에 가졌습니다.

CAP-008 구현은 이를 분리합니다.

```text
Target Repository
  = 사용자가 실제 수정할 Git repository

Catalog Root
  = registry + optional Skill source가 있는 Playbook 위치
```

## 구현

변경:

```text
harness/activation/playbook_launch.py
harness/activation/discovery_bridge.py
harness/activation/skill_materializer.py

verify-install.ps1
uninstall.ps1
install.sh

docs/QUICKSTART.md

```

추가:

```text
harness/activation/test_installed_launcher.py
```

## Catalog 자동 탐색

Launcher 기본 Catalog Root:

```python
Path(__file__).resolve().parents[2]
```

따라서:

```text
Source checkout
<playbook-repo>/harness/activation/playbook_launch.py
-> <playbook-repo>/capability-library

Installed
~/.codex/playbook-harness/activation/playbook_launch.py
-> ~/.codex/capability-library
```

사용자는 정상 사용에서 Catalog Root를 지정하지 않습니다. `--catalog-root`는 테스트/진단 override입니다.

## 설치 Layout

Windows:

```text
%USERPROFILE%\.codex\
  AGENTS.md
  playbook-harness\
  capability-library\

%USERPROFILE%\.agents\skills\
  <Core managed Skills 7개>
```

Optional Skill은 `.agents/skills`에 영구 설치하지 않습니다.

## Materializer / Bridge 계약

- `root`: target Git repository
- `catalog_root`: Playbook registry / optional Skill source
- runtime은 target repo 내부 `.playbook-runtime`에만 생성
- optional source는 `<catalog-root>/capability-library` 아래만 허용
- target repo에 `capability-library`를 복사하지 않음
- 기존 CAP-006 Codex discovery argv 계약 유지

## Installer

`install.ps1` / `install.sh`:

- capability library를 `~/.codex/capability-library`에 설치
- recursive SHA256 fingerprint 기반 idempotent 비교
- 변경 시 기존 설치 backup 후 교체

`verify-install.ps1`:

- source / installed capability library fingerprint 비교

`uninstall.ps1` / `uninstall.sh`:

- managed installed capability library 제거

PATH, shell profile, Codex executable은 수정하지 않습니다.

## Quickstart

설치 후 임의의 Git repository에서:

```cmd
python "%USERPROFILE%\.codex\playbook-harness\activation\playbook_launch.py" --root . --task "<작업>"
```

```cmd

```

## 목적

Deterministic Capability Router가 선택한 Capability를 실제로 활성화하기 전에, Registry metadata와 permission/type만 사용하여 안전한 activation plan을 생성합니다.

이 Task는 **dry-run only**입니다.

실제 Skill 복사/로드, MCP 연결, Agent spawn, network 호출, credential 사용, external/database write는 하지 않습니다.

## Decision 계약

각 선택 Capability는 다음 중 하나로 분류합니다.

```text
AUTO_ALLOWED
PROFILE_GATED
NETWORK_REVIEW
HUMAN_GATE_REQUIRED
MANUAL_ONLY
```

전체 결과는 선택이 없으면:

```text
RESULT     NO_ACTION
```

하나 이상 있으면:

```text
RESULT     PLANNED
```

## Decision 우선순위

강한 제한이 항상 약한 제한보다 우선합니다.

1. `credential_access`, `external_write`, `database_write`, `destructive`, `production`
   -> `HUMAN_GATE_REQUIRED`
2. Capability type이 `mcp` 또는 `agent`
   -> `MANUAL_ONLY` (P0 정책)
3. `network` 또는 `browser_control`
   -> `NETWORK_REVIEW`
4. `process_exec`, `local_write`
   -> `PROFILE_GATED`
5. `local_read` only
   -> `AUTO_ALLOWED`

민감 권한과 MCP/Agent가 동시에 있으면 `HUMAN_GATE_REQUIRED`가 우선합니다.

## Profile 규칙

- Router가 추천한 최종 Profile보다 약하게 낮추지 않음
- `HUMAN_GATE_REQUIRED`는 profile과 별개의 승인 Gate
- `NETWORK_REVIEW`는 network 목적/대상 확인 전 실제 실행 금지
- `PROFILE_GATED`는 선택된 Profile의 verification/Task scope 규칙 안에서만 실행 후보
- `AUTO_ALLOWED`도 실제 side effect를 발생시키지 않는 Skill/procedure에 한함

## Allowed

- `harness/activation/capability_manager.py`
- focused tests/fixtures
- MANIFEST 갱신
- V8.1 관련 Task/PR 상태 문서 갱신
- 필요한 경우 Registry metadata를 읽기 위한 기존 public helper 재사용

## Forbidden

- 실제 `.agents/skills` 복사/삭제
- 실제 MCP config 변경/연결/설치/기동
- Agent spawn
- network 호출
- credential 접근
- GitHub write 실행
- DB write
- destructive/production action
- `.codex/AGENTS.md` 확대
- LLM/API 호출
- 기존 Router scoring 의미 변경
- V8 Quality Gate 계약 변경

## Acceptance Criteria

1. trivial task -> `NO_ACTION`
2. `security-review` -> `AUTO_ALLOWED`
3. `testing` -> `PROFILE_GATED`
4. `documentation-lookup` -> `NETWORK_REVIEW`
5. `github-ops` -> `HUMAN_GATE_REQUIRED`
6. synthetic read-only MCP -> `MANUAL_ONLY`
7. synthetic read-only Agent -> `MANUAL_ONLY`
8. synthetic sensitive MCP/Agent -> `HUMAN_GATE_REQUIRED` 우선
9. Router profile 유지
10. machine-readable JSON 출력
11. 실제 side effect 없음
12. Harness Audit PASS
13. STRICT Quality Gate + Harness Audit PASS
14. test 후 working tree clean

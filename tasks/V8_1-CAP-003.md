## 목적

Deterministic Capability Router가 선택한 Capability를 실제로 활성화하기 전에, Registry metadata와 permission/type만 사용하여 안전한 activation plan을 생성합니다.

이 Task는 **dry-run only**입니다.

실제 Skill 복사/로드, MCP 연결, Agent spawn, network 호출, credential 사용, external/database write는 하지 않습니다.

## Decision 계약

각 선택 Capability는 다음 중 하나로 분류합니다.

```text
AUTO_ALLOWED
PROFILE_GATED
NETWORK_REVIEW
HUMAN_GATE_REQUIRED
MANUAL_ONLY
```

전체 결과는 선택이 없으면:

```text
RESULT     NO_ACTION
```

하나 이상 있으면:

```text
RESULT     PLANNED
```

## Decision 우선순위

강한 제한이 항상 약한 제한보다 우선합니다.

1. `credential_access`, `external_write`, `database_write`, `destructive`, `production`
   -> `HUMAN_GATE_REQUIRED`
2. Capability type이 `mcp` 또는 `agent`
   -> `MANUAL_ONLY` (P0 정책)
3. `network` 또는 `browser_control`
   -> `NETWORK_REVIEW`
4. `process_exec`, `local_write`
   -> `PROFILE_GATED`
5. `local_read` only
   -> `AUTO_ALLOWED`

민감 권한과 MCP/Agent가 동시에 있으면 `HUMAN_GATE_REQUIRED`가 우선합니다.

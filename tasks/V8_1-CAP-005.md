## 목적

Router와 Activation Policy가 선택한 optional Skill만 Task/session 전용 staging 영역에 materialize하고, manifest/hash로 무결성을 기록한 뒤 안전하게 cleanup하는 프로토타입을 구현합니다.

이번 Task는 **local staging prototype**입니다.

로컬 Codex가 실행 중인 세션에서 `.agents/skills` 변경을 즉시 hot-reload한다고 가정하지 않습니다. 실제 Codex discovery 경로 연결은 후속 Task에서 별도로 검증합니다.

## 핵심 원칙

1. optional Skill 전체를 상시 discovery 경로에 설치하지 않음
2. Router가 선택한 Skill만 대상
3. `AUTO_ALLOWED` Skill은 materialize 가능
4. `PROFILE_GATED` Skill은 Router 최종 Profile이 STANDARD/STRICT일 때만 materialize 후보
5. `NETWORK_REVIEW`, `HUMAN_GATE_REQUIRED`, `MANUAL_ONLY`은 자동 materialize 금지
6. MCP/Agent/CLI/REST wrapper는 CAP-005 대상 아님
7. source와 materialized copy SHA256 기록
8. 기존 session directory overwrite 금지
9. cleanup은 playbook이 생성한 manifest가 있는 session만 삭제
10. symlink/path traversal을 허용하지 않음
11. 실제 network/credential/external write/process execution 없음
12. `.codex/AGENTS.md` 확대 없음

## CLI 계약

Prepare:

```cmd
python harness\activation\skill_materializer.py prepare --root . --task "<task>" --target .playbook-runtime --session <id>
```

Status / integrity check:

```cmd
python harness\activation\skill_materializer.py status --target .playbook-runtime --session <id>
```

Cleanup:

```cmd
python harness\activation\skill_materializer.py cleanup --target .playbook-runtime --session <id>
```

## Materialization 정책

### AUTO_ALLOWED

Skill이면 자동 materialize.

### PROFILE_GATED

Skill이고 최종 Profile이 `standard` 또는 `strict`이면 materialize.

Profile이 `minimal`이면 skip.

### NETWORK_REVIEW / HUMAN_GATE_REQUIRED / MANUAL_ONLY

자동 materialize하지 않음.

## Security / Integrity

- session id는 안전한 제한 문자만 허용
- source path는 Registry가 검증한 Library root 하위여야 함
- source symlink 금지
- target session collision 시 FAIL
- cleanup은 `managed_by=codex-ai-agent-playbook-v8.1` manifest가 없으면 거부
- status는 materialized file hash drift를 FAIL 처리

## Allowed

- `harness/activation/skill_materializer.py`
- focused tests
- `.gitignore`의 runtime staging 제외
- `MANIFEST.txt`
- CAP-005/PR 문서 갱신

## Forbidden

- 실제 `~/.agents/skills` 변경
- Repository `.agents/skills`에 optional Skill 설치
- Codex 재시작/실행 자동화
- MCP 설치/연결
- Agent spawn
- network 호출
- credential 접근
- process execution from capability content
- external/database write
- LLM/API routing

## Acceptance Criteria

1. trivial task -> no session materialization
2. JWT/regression task -> selected 3 Skill materialize
3. materialized ids가 Router 결과와 일치
4. source/destination SHA256 일치
5. status integrity PASS
6. tamper 후 status FAIL
7. duplicate session prepare FAIL
8. unsafe session id FAIL
9. wrapper/MCP/Agent는 materialize 대상 아님
10. unmanaged directory cleanup 거부
11. managed session cleanup PASS
12. cleanup 후 target residue 없음 또는 빈 base만 유지
13. existing Registry/Router/Manager tests 회귀 없음
14. Harness Audit PASS
15. STRICT Quality Gate PASS
16. final working tree clean

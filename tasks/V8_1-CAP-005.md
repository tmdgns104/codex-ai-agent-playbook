## 목적

Router와 Activation Policy가 선택한 optional Skill만 Task/session 전용 staging 영역에 materialize하고, manifest/hash로 무결성을 기록한 뒤 안전하게 cleanup하는 프로토타입을 구현합니다.

이번 Task는 **local staging prototype**입니다.

로컬 Codex가 실행 중인 세션에서 `.agents/skills` 변경을 즉시 hot-reload한다고 가정하지 않습니다. 실제 Codex discovery 경로 연결은 후속 Task에서 별도로 검증합니다.

## 구현

## Staging 구조

```text
.playbook-runtime/
  <session>/
    activation.json
    skills/
      security-review/
        SKILL.md
      testing/
        SKILL.md
```

이 staging 경로 자체는 Codex discovery 경로라고 주장하지 않습니다.

## Materialization 정책

- `AUTO_ALLOWED` Skill -> materialize
- `PROFILE_GATED` Skill -> 최종 Profile이 STANDARD/STRICT이면 materialize
- `NETWORK_REVIEW` / `HUMAN_GATE_REQUIRED` / `MANUAL_ONLY` -> 자동 materialize 금지
- non-Skill capability -> skip

JWT/regression 대표 Task에서는 목표 materialization이:

```text
security-review
testing
root-cause-debugging
```

입니다.

## Manifest / Integrity

- `schema_version`
- `managed_by=codex-ai-agent-playbook-v8.1`
- `session`
- `task`
- `profile`
- selected ids
- materialized ids / decision / source / destination
- source SHA256
- skipped ids/reasons
- `side_effects_executed=false`
- `staging_write_performed`
- `codex_discovery_ready=false`

`status`는 materialized file set 및 SHA256 drift를 검사합니다.

## Safety

- session id 제한
- Registry Library root 밖 source 거부
- source symlink 거부
- 기존 session overwrite 거부
- unmanaged manifest cleanup 거부
- cleanup은 자신의 session directory만 제거
- 실제 `~/.agents/skills` 변경 없음
- Repository `.agents/skills` 변경 없음
- network/credential/process execution/external write 없음

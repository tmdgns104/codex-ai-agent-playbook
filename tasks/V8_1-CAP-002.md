## 목적

Capability Registry 전체 본문이나 외부 Skill 내용을 LLM Context에 넣지 않고, 짧은 metadata만 사용해 현재 Task에 필요한 최소 Capability 후보를 결정론적으로 추천합니다.

이 Task는 **selection / recommendation only** 입니다.

실제 Skill 활성화, MCP 연결, Agent spawn, credential 사용, 외부 write는 하지 않습니다.

## 구현 결과

- `harness/router/scoring.py`
- `harness/router/capability_router.py`
- `harness/router/test_capability_router.py`
- 초기 6개 Capability에 한국어 routing trigger 추가
- MANIFEST 갱신

구현 원칙:

1. zero-capability 허용
2. 전체 선택 수 기본 최대 3개
3. MCP 최대 1개
4. Agent 최대 1개
5. Skill/CLI/REST보다 MCP와 Agent 선택 임계값을 높게 유지
6. deterministic metadata matching 우선
7. LLM/API 호출 없음
8. Capability 본문/SKILL.md를 routing 입력으로 사용하지 않음
9. 동일 입력 + 동일 Registry는 동일 결과
10. 선택 이유와 score를 출력
11. selected Capability 중 가장 강한 verification profile을 최종 추천
12. 민감 permission은 approval required metadata로 표시

### JWT / auth / regression routing

실행:

```cmd
python harness\router\capability_router.py --root . --task "JWT 인증 오류를 수정하고 regression test를 실행"
```

실제 선택:

```text
security-review  score=12  profile=STRICT
code-review      score=5   profile=STANDARD
testing          score=5   profile=STANDARD

PROFILE    STRICT
COUNT      3
RESULT     ROUTED
```

`security-review`가 JWT/인증 신호로 가장 높은 점수를 받았고, regression 신호로 `testing` 및 `code-review`가 선택되었습니다. 전체 선택 상한 3개를 지켰습니다.
